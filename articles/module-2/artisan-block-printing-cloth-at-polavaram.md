# Artisan block-printing cloth at Polavaram

## Studio vs Documentary Context

Workshop photograph with windows, table and tools visible.

Course reading: The caption names the workshop of the late Mukkatieswarudu Rao.

## Subject & Evidence

A standing artisan presses a rectangular block onto a broad cloth-covered table. Patterned fabric hangs over the front edge. Repeated placement of a block is a different action from drawing each contour with a pen.

## Distinctions

**Exam distractor:** “The Polavaram demonstration uses the same freehand drawing action as the Srikalahasti photograph.”

**Why it is wrong:** The Polavaram artisan presses a block onto cloth; the Srikalahasti artisan draws contours. Repeating a prepared matrix and drawing a line are distinct visible actions.
